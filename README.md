# Mobile Jarvis

Личное Telegram Mini App: быстрые записи мыслей, задач и файлов в облачный ящик, который потом забирается на компьютер.

Работает только у владельца: сервер проверяет подпись Telegram и ID пользователя. В этом репозитории только интерфейс, секретов здесь нет.

`.github/workflows/keepalive.yml` раз в 6 дней обращается к базе, чтобы бесплатный проект Supabase не засыпал.
